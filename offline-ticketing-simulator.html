Offline-First Workflow Simulator

Interactive Web Application & Systems Architecture

An interactive, offline-first workflow simulator built to demonstrate product management and business analysis principles. This web application models a digital ticketing and baggage collection system for high-footfall, low-connectivity environments like rural transit hubs.

The Core Challenge

In operational environments like transit hubs and temple queues, network drops are inevitable. Operators cannot stop processing passengers or baggage just because the server timed out. The challenge was to design a system that seamlessly handles data intake locally and reconciles with the main server automatically once connectivity is restored.

System Features & Edge Cases Handled

  • Role-Based Routing: Distinct UI workflows for bus ticketing vs. static baggage collection counters.
  • Edge Computing Simulation: Utilizes browser localStorage to safely queue transactions when the network state is red.
  • Hardware Realities: Built-in simulated thermal receipts and inclusive custom baggage tokens for users without mobile devices.
  • MIS & Reconciliation: End-of-shift dashboard summarizing operational metrics with raw CSV export capabilities for back-office auditing.
